## Python

- [Python 3.15's JIT is now back on track](https://fidget-spinner.github.io/posts/jit-on-track.html)
    - 이 기사는 macOS AArch64에서 11-12%, x86_64 Linux에서 5-6%의 속도 향상을 달성했으며, 이는 복잡한 문제를 관리 가능한 작업으로 분해하고, trace recording 프론트엔드 재작성(dual dispatch 메커니즘으로 코드 커버리지 50% 증가), 그리고 reference count elimination 같은 최적화를 커뮤니티 기여자들과 함께 병렬화한 결과를 소개합니다.

## JS/TS/FP

- [18 Months of Code, Gone. Here's What We Learned.](https://tompiagg.io/posts/we-threw-away-1-5-years-of-code)
    - 이 기사는 18개월 분량의 코드를 버린 경험을 공유합니다. Autonoma 팀은 고객 기반 성장에도 불구하고 전체 코드베이스를 재작성하기로 결정했는데, 그 이유는 테스트 없는 unstrict TypeScript로 인한 버그 폭증과 고객 이탈, 그리고 GPT-4 시대에 불필요해진 복잡한 Playwright/Appium guardrails 때문이었습니다. Next.js Server Actions의 치명적 결함들(전역 순차 실행, 테스트 어려움, 관찰 불가능성, 보안 위험)을 해결하기 위해 React + tRPC + Hono 스택으로 전환했고, 오케스트레이션은 useworkflow나 Temporal 대신 Kubernetes 네이티브인 Argo를 선택했습니다. 이번 재작성을 통해 strict TypeScript와 테스트 우선 접근으로 기술 부채를 청산하고 agentic 솔루션으로 진화하는 계기가 되었다고 강조합니다.

## Data

- [Bayesian statistics for confused data scientists](https://nchagnet.eu/blog/bayesian-statistics-for-confused-data-scientists)
    - 이 기사는 혼란스러운 데이터 사이언티스트를 위한 베이지안 통계는 빈도주의(frequentist)와 베이지안 접근법의 철학적 차이를 설명하며, 베이지안 통계가 파라미터를 고정된 값이 아닌 불확실성을 가진 분포로 취급하여 사전 지식(prior)과 데이터(likelihood)를 결합해 사후 분포(posterior)를 구한다는 점을 강조합니다.
