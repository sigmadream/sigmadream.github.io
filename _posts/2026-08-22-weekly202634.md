## Python

- [Django is moving to an annual release cycle](https://www.djangoproject.com/weblog/2026/aug/10/annual-release-cycle/)
    - 이 기사는 Django 프로젝트가 DEP 20을 통해 기존의 8개월 배포 주기에서 벗어나 2028년 1월(Django 2028)부터 연례 배포 주기로 전환한다는 공식 발표를 다룹니다.
    - 별도의 LTS 구분을 없애고 매년 출시되는 모든 기능 릴리스에 3년(일반 버그 수정 1년, 보안 및 데이터 손실 수정 2년)의 지원 기간을 부여하며, 매년 10월 출시되는 파이썬의 배포 일정과 호흡을 맞춰 업그레이드 예측 가능성을 높인 배경을 설명합니다.

- [A quick look at zero-knowledge proofs](https://bernsteinbear.com/blog/zkp/)
    - 이 기사는 블록체인이나 암호화폐 맥락을 덜어내고, 컴퓨터 과학과 그래프 이론 관점에서 영지식 증명(Zero-Knowledge Proofs)의 핵심 원리를 간결하게 소개하는 글입니다.
    - 인접한 노드가 같은 색을 갖지 않도록 세 가지 색으로 그래프를 칠하는 그래프 3-채색 문제를 예제로 삼아, 실제 해답을 노출하지 않으면서도 해답을 알고 있음을 검증자에게 납득시키는 대화형 증명 과정을 약 30줄의 가벼운 구현 코드와 함께 보여줍니다.

- [Numba in the Browser: Unlocking a New Scientific Python Stack in JupyterLite](https://notebook.link/blog/numba-in-the-browser/)
    - 이 기사는 파이썬 JIT 컴파일러인 Numba를 WebAssembly 환경으로 이식해 별도의 서버 백엔드 없이 웹 브라우저(JupyterLite) 안에서 직접 구동하는 데 성공한 기술적 성과를 다룹니다.
    - 브라우저의 실행 메모리 생성 제약과 `llvmlite`/LLVM 의존성 문제를 `emscripten-forge` 기반으로 극복해, 파이썬 함수를 LLVM IR과 WebAssembly로 컴파일하고 동적 링크하여 브라우저 내 과학 연산 성능을 대폭 끌어올린 과정을 설명합니다.

## JS/TS/FP

- [Testing Google's "modern-web-guidance" skill against a real React app](https://alfy.blog/2026/07/25/modern-web-guidance.html)
    - 이 기사는 AI 코딩 에이전트가 오래된 학습 데이터 때문에 구식 웹 코드를 작성하는 문제를 줄이기 위해 구글이 공개한 `modern-web-guidance` 스킬을 실제 Vite + React 18 애플리케이션에 적용해 본 후기입니다.
    - Baseline 브라우저 호환성 데이터를 바탕으로 다크 모드를 위한 네이티브 `color-scheme` 선언, `100vh` 대신 `100dvh` 사용, 커스텀 JS 검증 대신 `:user-invalid` 의사 클래스 활용 등 기존 코드베이스에서 놓치고 있던 최신 웹 플랫폼 기능들을 어떻게 찾아내고 개선했는지 정리합니다.
