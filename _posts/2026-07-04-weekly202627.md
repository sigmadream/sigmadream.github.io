## Python

- [TIRx: An Open Compiler Stack for Evolving Frontier ML Kernels](https://tvm.apache.org/2026/06/22/tirx)
    - Apache TVM 위에 만든 오픈 컴파일러 스택으로, ML 커널의 하드웨어 경계 근처를 직접 다루는 저수준 DSL과 디스패치 중심 컴파일 모델을 제안합니다. 레이아웃을 저장 계약으로 두고, intrinsic을 먼저 노출한 뒤 tile primitive로 승격하는 방식으로 새로운 GPU와 가속기 세대를 따라갈 수 있게 설계했으며, B200 기준 GEMM과 FlashAttention 계열에서 상당히 경쟁적인 성능을 보였다고 설명합니다.

- [Build a fully local voice assistant in 2026](https://blog.platypush.tech/article/Local-voice-assistant)
    - Platypush를 이용해 wake word, STT, TTS, 자동화 실행까지 로컬에서 돌리는 음성 비서를 만드는 실전 가이드입니다. OpenWakeWord, Vosk, Piper를 조합해 LAN 안에서만 동작하는 구조를 만들고, 필요할 때만 OpenAI 호환 로컬 LLM을 fallback으로 붙이며, 홈 오토메이션 이벤트와 알림까지 확장하는 방법을 보여줍니다.

- [Write a coding agent from first principles](https://mathspp.com/blog/write-a-coding-agent-from-first-principles)
    - LLM을 단순 채팅이 아니라 도구를 호출하는 에이전트로 확장하는 과정을 단계별로 설명하는 튜토리얼입니다. 대화 컨텍스트 관리, 사용자 명령 처리, 파일 읽기 도구, Claude tool use 블록, bash와 파일 편집 도구까지 구현하면서 "에이전트는 결국 메타데이터와 파싱의 문제"라는 점을 체계적으로 보여줍니다.
