## Python

- [AI Engineering from Scratch](https://aiengineeringfromscratch.com/)
    - 이 기사는 기초 수학부터 대규모 언어 모델과 멀티 에이전트 시스템까지 AI 엔지니어링의 핵심 개념을 밑바닥부터 직접 구현하며 배우는 무료 오픈소스 커리큘럼을 소개합니다.
    - PyTorch 같은 고수준 프레임워크나 블랙박스 API에 바로 의존하는 대신 표준 라이브러리만으로 신경망, 토크나이저, 어텐션 메커니즘 등을 직접 작성해 보게 하며, 20개 단계의 500여 개 레슨마다 프롬프트나 에이전트, MCP 서버 같은 실질적인 결과물을 만들어 내도록 구성되어 있습니다.

- [Building an Ultra-High Throughput AI-SQL Engine](https://fsdatalab.github.io/blog/introducing-quail/)
    - 이 기사는 SQL 쿼리 안에 LLM 연산을 직접 결합한 AI-SQL 워크로드를 초고속으로 처리하기 위해 카네기멜론 대학교 연구진과 Modal이 개발한 오픈소스 실행 엔진 Quail을 다룹니다.
    - 일반 대화형 요청에 맞춘 기존 서빙 엔진으로 대규모 테이블 조인이나 행 단위 LLM 평가를 수행할 때 발생하는 심각한 병목을 해결하기 위해, 데이터베이스 쿼리 플래너와 LLM 추론 계층을 공동 최적화하여 단일 H100 GPU에서 분당 10억 개 이상의 토큰을 처리하는 아키텍처를 설명합니다.

- [Language Models for Text Classification: From Bag-of-Words to Jev](https://magazine.sebastianraschka.com/p/classifier-history-and-jev)
    - 이 기사는 자연어 처리 분야에서 텍스트 분류 기법이 초기의 통계적 방식부터 최신 의사결정 모델에 이르기까지 어떻게 발전해 왔는지 역사적 흐름과 아키텍처 변화를 정리한 글입니다.
    - Bag-of-Words와 로지스틱 회귀, RNN 및 CNN을 거쳐 BERT 같은 인코더와 GPT 계열 디코더 모델을 활용한 분류 방식을 비교하고, 별도의 파인튜닝 없이도 사용자 정의 레이블에 대해 보정된 확률 분포를 반환하는 제로샷 의사결정 모델(Jev)의 작동 원리와 실무 벤치마크를 함께 설명합니다.

## JS/TS/FP

- [How to Sync a Design System with Claude Design](https://nitayneeman.com/blog/how-to-sync-a-design-system-with-claude-design/)
    - 이 기사는 Claude Code의 `/design-sync` 명령어를 활용해 실제 프로덕션 React 디자인 시스템을 Claude Design 환경과 동기화하는 방법을 다룹니다.
    - AI가 임의의 유사 컴포넌트를 생성하는 대신 코드베이스의 실제 컴포넌트를 그대로 렌더링할 수 있도록, 런타임 번들과 CSS 디자인 토큰, TypeScript 타입 정의(`.d.ts`), 컴포넌트 사용 가이드라인을 미러링하고 Storybook으로 시각적 정합성을 검증하는 실무 워크플로우를 상세히 소개합니다.

- [WebXR Tutorial: Getting Started With Three.js and No Game Engine](https://newsnix.com/articles/webxr-threejs-tutorial-getting-started-no-engine/)
    - 이 기사는 Unity나 Unreal 같은 무거운 상용 게임 엔진 없이 Three.js와 표준 WebXR API만으로 웹 기반의 가벼운 VR 및 AR 환경을 구축하는 입문 가이드를 다룹니다.
    - `WebGLRenderer`에서 XR 모드를 활성화하고 세션 진입 버튼을 구성하는 기초 설정부터, 헤드셋의 주사율에 맞춰 일반 `requestAnimationFrame` 대신 `setAnimationLoop`를 사용해야 하는 이유와 컨트롤러 입력 이벤트를 처리하는 방법까지 단계별로 설명합니다.
