## Python

- [Fine-Tuning SOTA Object Detection Models on Real-World Datasets](https://blog.jetbrains.com/pycharm/2026/08/fine-tuning-sota-object-detection-models-on-real-world-datasets/)
    - 이 기사는 YOLO12, YOLO26, RF-DETR 같은 최신(SOTA) 객체 탐지 모델을 표준 벤치마크가 아닌 실제 산업 현장 데이터셋에 맞게 파인튜닝하는 방법을 다루는 실전 가이드입니다.
    - PyCharm 안에서 모델 계열별로 독립된 `uv` 가상 환경을 구성하는 방법부터, 제조 결함(케이블 손상), 유통(음료 병), 의료(골절 X-ray) 등 도메인 특성이 뚜렷한 데이터셋에서 학습을 진행하고 $\text{mAP}_{50}$ 지표로 성능을 비교 분석하는 과정을 설명합니다.

- [Unit testing with wrapture](https://grahamdumpleton.me/posts/2026/09/unit-testing-with-wrapture/)
    - 이 기사는 `wrapt` 제작자인 Graham Dumpleton이 표준 라이브러리의 `unittest.mock` 대신 자신이 만든 `wrapture` 라이브러리를 활용해 단위 테스트를 작성하는 방법을 소개하는 글입니다.
    - 실제 객체를 가짜 객체로 대체(substitution)하는 기존 모킹 방식과 달리, `wrapt` 기반의 안전한 래핑(wrapping)을 통해 원래의 호출 그래프를 그대로 유지하면서 인자와 반환값을 관찰 및 변환하고, 공유 타임라인으로 에러 경로에서 특정 호출이 일어나지 않았음을 검증하는 기법을 설명합니다.
