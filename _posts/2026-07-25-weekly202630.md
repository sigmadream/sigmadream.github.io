## Python

- [What Every Python Developer Should Know About the CPython ABI](https://labs.quansight.org/blog/python-abi-abi3t)
    - 이 기사는 CPython ABI와 stable ABI3의 차이를 중심으로, Python 확장 모듈을 만들 때 왜 ABI를 이해해야 하는지 설명하는 글입니다. 
    - C/C++/Rust 같은 네이티브 코드를 연결하는 확장 모듈이 Python 버전이 바뀔 때마다 재빌드되어야 하는 이유, 그리고 ABI3를 쓰면 어떤 호환성과 배포상의 이점이 생기는지를 실무 관점에서 정리한 내용으로 보입니다.

- [Browser Push Notifications for a Django Website](https://www.djangotricks.com/blog/2026/06/browser-push-notifications-for-a-django-website/)
    - 이 기사는 Django 웹사이트에 브라우저 푸시 알림을 붙이는 방법을 다루는 실전 가이드입니다. 
    - Web Push, VAPID, Service Worker, 구독 등록 흐름, 그리고 특정 사용자에게 알림을 보내는 서버 쪽 구현까지 포함해, Django 앱에 브라우저 알림 기능을 붙이려는 개발자를 위한 단계별 설명으로 보입니다.

## JS/TS/FP

- [I stopped destructuring everything](https://allthingssmitty.com/2026/07/13/i-stopped-destructuring-everything/)
    - 이 기사는 자바스크립트에서 모든 객체를 습관적으로 구조 분해하지 않게 된 이유를 설명합니다.
    - 저자는 destructuring이 코드를 짧게 만들 수는 있지만, 나중에 읽을 때 변수의 출처와 객체의 맥락을 잃게 만들어 오히려 이해 비용을 높일 수 있다고 보고, 필요한 경우에만 destructuring을 쓰고 나머지는 post.title처럼 객체 경로를 유지하는 쪽이 더 읽기 쉽다고 주장합니다.

- [200.milliseconds](https://200ms.thenodebook.com/#act-0-prologue)
    - 이 기사는 하나의 HTTP 요청이 약 200밀리초 동안 거치는 전체 경로를 시각화한 인터랙티브 콘텐츠입니다.
    - DNS, TCP, TLS, 커널, Node.js 이벤트 루프, Postgres 같은 구성 요소를 시간축 위에서 따라가며, 사용자가 체감하지 못하는 짧은 지연 속에 어떤 단계들이 숨어 있는지 보여주는 설명형 작품입니다.
