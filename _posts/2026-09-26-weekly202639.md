## Python

- [Pandas Should Go Extinct](https://eddie.codes/posts/pandas-should-go-extinct/)
    - 이 기사는 파이썬 데이터 분석 생태계의 표준처럼 쓰여 온 `pandas`가 현대의 워크로드에서는 실용적인 수명을 다했으며 더 나은 대안으로 대체되어야 한다고 주장하는 글입니다.
    - 데이터가 수십~수백 기가바이트 규모로 커질 때 `pandas`의 메모리 비효율과 느린 연산 속도 때문에 굳이 필요하지도 않은 Spark나 Databricks 같은 무거운 분산 시스템으로 성급하게 넘어가는 문제를 지적하고, 100GB 안팎의 중간 규모 데이터는 단일 머신에서 Polars나 DuckDB로 훨씬 빠르고 간결하게 처리할 수 있다고 설명합니다.

- [Finch meets MLIR](https://labs.quansight.org/blog/finch_meets_mlir)
    - 이 기사는 희소 텐서(sparse tensor) 대수를 위한 도메인 특화 언어이자 컴파일러인 Finch(`finch-tensor`)에 LLVM의 MLIR 기반 컴파일러 백엔드를 새롭게 구현한 과정을 다룹니다.
    - 기존 CPU 중심이던 희소 텐서 연산을 GPU나 SIMD 가속기로 확장하기 위해 MLIR 방언(dialect)과 컴파일러 파이프라인을 구축한 아키텍처를 소개하고, `scipy.sparse` 배열과의 연동 및 Numba 등 기존 백엔드와의 성능 비교 결과를 함께 정리합니다.

## JS/TS/FP

- [What It Actually Takes to Migrate Discord to React Native's New Architecture](https://swmansion.com/blog/what-it-actually-takes-to-migrate-discord-to-react-native-s-new-architecture/)
    - 이 기사는 Software Mansion이 Discord의 대규모 모바일 앱을 Android부터 iOS까지 순차적으로 React Native의 새로운 아키텍처(New Architecture)로 마이그레이션하며 겪은 실전 엔지니어링 과제를 다룹니다.
    - 단순히 설정 플래그를 켜는 것을 넘어 새로운 C++ 렌더링 코어인 Fabric의 뷰 평탄화(view flattening)와 동기식 레이아웃 때문에 깨지는 기존 좌표 계산 가정, 복잡한 제스처 인터럽트 처리, 앱 초기화 시 발생하는 경쟁 조건 등 방대한 롱테일 버그와 성능 회귀를 어떻게 추적하고 해결했는지 상세히 공유합니다.

- [12 CSS features you can use today with no build step](https://flaviocopes.com/modern-css-features/)
    - 이 기사는 Sass 같은 전처리기나 복잡한 빌드 도구, 혹은 자바스크립트 우회 코드 없이 오늘날 브라우저에서 바로 사용할 수 있는 12가지 최신 네이티브 CSS 기능을 소개합니다.
    - 네이티브 CSS 중첩(Nesting), 부모 선택자 역할을 하는 `:has()` 의사 클래스, 컨테이너 쿼리, 서브그리드(Subgrid), `oklch()` 및 `color-mix()` 색상 함수, 스크롤 기반 애니메이션, 동적 뷰포트 단위(`dvh`, `svh`, `lvh`) 등 실무 스타일시트를 더 가볍고 유지보수하기 쉽게 만들어 주는 기능들을 정리합니다.
