## Python

- [Making a Python interpreter in 1024 bytes](https://austinhenley.com/blog/python1024.html)
    - 이 기사는 외부 라이브러리나 매크로 꼼수 없이 순수 C 코드 1024바이트(1KB) 이내로 파이썬 문법의 부분집합을 실행하는 초소형 인터프리터를 직접 구현한 도전기를 다룹니다.
    - FizzBuzz 프로그램을 실행할 수 있는 수준을 목표로 삼아 들여쓰기 블록과 콜론, 괄호 없는 조건문 등 파이썬다운 문법 형태를 유지하면서도, 엄격한 용량 제한을 맞추기 위해 단일 문자 토큰 매칭 등으로 파서를 극한까지 압축한 과정을 설명합니다.

- [Python sets and dictionaries can have quadratic-time performance](https://lemire.me/blog/2026/09/03/python-sets-and-dictionaries-can-have-quadratic-time-performance/)
    - 이 기사는 흔히 평균 $O(1)$ 상수 시간으로 동작한다고 알려진 파이썬의 `set`과 `dict` 자료구조가 특정 조건에서 최악의 경우 $O(n^2)$ 시간 복잡도로 급격히 느려질 수 있음을 보여주는 글입니다.
    - 메르센 소수(`(1 << 61) - 1`)의 배수처럼 동일한 해시값을 만들어내는 정수 키들을 의도적으로 주입해 해시 충돌을 유발하면, 개별 삽입 및 탐색 비용이 $O(n)$으로 퇴화하여 전체 작업 시간이 이차 시간으로 증가하는 현상을 실험으로 설명합니다.

## JS/TS/FP

- [The Browser's Main Thread Is Expensive](https://kciter.so/posts/the-expensive-main-thread/en/)
    - 이 기사는 프론트엔드 성능 최적화를 단순한 번들 크기 축소나 네트워크 지연을 넘어 브라우저 메인 스레드의 동작 원리와 사용자 체감 반응성 관점에서 깊이 있게 다루는 인터랙티브 가이드입니다.
    - 60FPS 화면 유지를 위해 스크립트에 허용된 약 10ms의 프레임 예산을 설명하고, 긴 작업 분할(`scheduler.yield`, `requestAnimationFrame`)과 이벤트 배칭으로 메인 스레드를 현명하게 쓰는 전략부터 Web Worker와 컴포지터 스레드(`transform`, `opacity`)를 활용해 메인 스레드 부하를 덜어내는 방법까지 시각적 시뮬레이션과 함께 정리합니다.
