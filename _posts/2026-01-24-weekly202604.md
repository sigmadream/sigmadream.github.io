## Python

- [What's New in pandas 3.0: Expressions, Copy-on-Write, and Faster Strings](https://codecut.ai/pandas-3-whats-new/)
    - 이 기사는 pandas 3.0에서 새로 도입된 표현식(Expression) API, 기본 Copy-on-Write 모드, 더 빠른 문자열 처리 및 타입 안정성을 중심으로, 기존 체인 연산의 성능, 메모리 사용을 개선하고 디버깅을 단순화하는 변경 사항을 요약하면서, 코드 예제로 마이그레이션 시 고려할 점을 설명합니다.

- [Django Time-Based Lookups Performance](https://johnnymetz.com/posts/django-time-based-lookups-performance/)
    - 이 기사는 Django 타임 기반 조회 글은 `timestamp__date=...` 같은 필드 lookup이 인덱스를 못 쓰고 전체 테이블 스캔으로 느려지는 사례를 보여주고, 표현식 인덱스 대신 `timestamp__gte` 등과 같은 범위 조회로 기존 인덱스를 활용해 30초짜리 쿼리를 1초 미만으로 줄이는 패턴을 제안하며, `__range` 주의 사항과 집계 쿼리에서도 동일한 원리가 적용됨을 정리합니다.
    
## JS/TS/FP

- [Where React performance issues start](https://playfulprogramming.com/posts/where-react-performance-issues-start/)
    - 이 기사는 React에서 "렌더링"이 DOM 페인트가 아니라 컴포넌트 함수를 실행해 VDOM 트리를 만드는 과정이라는 점을 강조하고, 인위적으로 무거운 렌더 작업을 넣어 입력이 심각하게 랙 걸리는 예제를 통해, 대부분의 성능 문제는 DOM 업데이트가 아니라 렌더 단계에서 불필요하게 많은 일을 하는 컴포넌트 설계에서 시작된다는 인사이트를 제공합니다.

- [jQuery 4.0.0](https://blog.jquery.com/2026/01/17/jquery-4-0-0/)
    - jQuery 4.0.0 릴리스 글은 20년 만의 메이저 업데이트로 IE<11 및 레거시 브라우저 지원 제거, Trusted Types 및 CSP 대응, 소스의 ES 모듈 전환, 오래된/중복된 API 대거 제거, W3C 스펙을 따르는 포커스 이벤트 순서 적용, slim 빌드에서 Deferred/Callbacks 제거 등 현대 브라우저·빌드 환경에 맞춘 정리와 함께, 대부분의 코드는 비교적 적은 변경으로 업그레이드 가능하다고 안내합니다.

## Data

- [Why DuckDB is my first choice for data processing](https://www.robinlinacre.com/recommend_duckdb/#why-duckdb-is-my-first-choice-for-data-processing)
    - DuckDB 글은 단일 머신에서의 분석 워크로드가 보편화되는 흐름 속에서, DuckDB가 설치, 시작이 매우 간단한 인프로세스 OLAP 엔진으로서 CSV/Parquet/JSON 파일을 직접 읽고 고성능 SQL을 실행할 수 있고, 다른 SQL 엔진 대비 100~1000배 빠른 경우도 있으며, 풍부한 SQL 확장(EXCLUDE, COLUMNS, QUALIFY, 함수 체이닝 등), 타입 제어, 지연 실행 기반 파이프라인 디버깅, ACID 지원, C++ UDF 및 커뮤니티 확장 생태계를 바탕으로 저자에게는 기본 데이터 처리 도구가 되었다는 경험을 공유합니다.
